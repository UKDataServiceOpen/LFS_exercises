This repository contains draft exercises to support the LFS data skills module. 

1. Estimates of temporary employment - a first exercise designed to help people get familar with the QLFS - size, key variables, the main weight, the effect of the grossing weight on counts.
2. The distribution of weekly earnings of full-time employees - a follow up exercise using the QLFS but focusing on earnings - key earnings variables, the earnings weight and when not to use the earnings weight.
3. Examining Labour Market Flows using the Labour Force Survey Two-Quarter Longitudinal Dataset - introduces the longitundial datasets - the structure of the dataset, key variables for examining flows, longitudinal weight

4. The aim will also be to introduce a 4th exercise that explores accounting for survey design (producing an estimate with CI using different weighting approaches, adjusting the CI using published design factors.
