Estimates of temporary employment

In this exercise, we will recreate an ONS labour market estimate published online in the table EMP07 Temporary Employees. Currently, this table is updated four times a year in February, May, August and November using the Quarterly Labour Force Survey (QLFS).

Learning outcomes:

  • To become more familiar with QLFS datasets.
  • To become familiar with producing weighted population estimates
  • To understand how some ONS estimates are produced

Data

The data used in this exercise relates to an estimate published by the ONS for October-December 2024.

To follow the exercise, you need to access the relevant dataset from the UK Data Service: SN 9349: Quarterly Labour Force Survey, October - December, 2024.

Getting weighted frequencies

To get correct estimates of population values, we need to apply the weight.

We will use as_survey_design(), an R function from the survey and srvyr packages, to create a weighted version of our data.

Let’s first examine the variable JOBTYP, which indicates whether respondents work in a temporary job or not.

cbind("Freq"=table(dataex1$JOBTYP), 
      "Pct"=  100*prop.table(table(dataex1$JOBTYP)) |> round(1) 
      )
                               Freq Pct
[-9] Does not apply           36698  60
[-8] No answer                   15   0
[1] Permanent                 25104  40
[2] Not permanent in some way  1252   0

Since we have missing values (e.g. ‘Does not apply’), we can mark them as system missing (NA in R) so they do not affect the analysis.

dataex1 <- dataex1 |> 
          mutate (
                 JobTmp = ifelse(JOBTYP == "[2] Not permanent in some way",
                                 "Temporary",
                                  "Not temporary"),
                 JobTmp = ifelse(JOBTYP == "[-9] Does not apply" | 
                                  JOBTYP == "[-8] No answer",
                                  NA,
                                  JobTmp),
                 JobTmp = as.factor(JobTmp)
                  )

cbind("Freq"=table(dataex1$JobTmp), 
      "Pct"=  (100*prop.table(table(dataex1$JobTmp))) |> round(1) 
      )
               Freq  Pct
Not temporary 25104 95.2
Temporary      1252  4.8

Now, create a version of the data with the weight applied, which we will use in the rest of the analysis.

dataex1.s<-dataex1|> 
         filter(!is.na(PWT24) ) |> #remove obs with missing weight value 
         as_survey_design(weights=PWT24)

Note: In the code above, we removed observations with missing weight values. These cases should not be taken into account when calculating population estimates – and if we don’t remove them, R will return an error message.

Now, compute the weighted frequencies of JobTmp.

t<-svytable(~JobTmp, dataex1.s)


cbind("Freq"=t, 
      "Pct"=  (100*prop.table(t)) |> round(1) 
      )
                  Freq  Pct
Not temporary 27802100 94.8
Temporary      1514206  5.2

Questions

  • Answers

  1. Do the frequencies change noticeably when the weight is applied?

  2. Using the code we used to create JobTmp above as guide, create a variable to indicate those working part time and examine their weighted and unweighted frequencies. You are going to need this variable later.

  1. Yes, the frequencies change quite a lot once we apply the weights — they become much higher. This is because the weights in the Labour Force Survey (LFS) are designed to sum to known population totals. That makes it easier to estimate overall population values like totals, means, and proportions.

    The LFS weights also account for the survey’s sample design: individuals who had a lower chance of being selected are given higher weights to correct for that. They also help adjust for different levels of non-response across subgroups in the population, which means the results are more likely to reflect the population accurately.

  2. The syntax below computes a variable recording whether respondents work part-time or not and produce weighted frequency tables.

 dataex1 <- dataex1 |> 
                  mutate (
                    PartTime = ifelse(FTPT == "[4] New Deal-PT" | FTPT  == "[2] Part time",
                                      "Part-time",
                                      "Not part-time"),
                   PartTime = ifelse(FTPT == "[-9] Does not apply" | FTPT == "[-8] No answer",
                                      NA,
                                      PartTime),

                    PartTime = as.factor(PartTime)
                  )


dataex1.s<-dataex1|> 
         filter(!is.na(PWT24) ) |> 
         as_survey_design(weights=PWT24)
