Estimates of temporary employment

In this exercise, we will recreate ONS labour market analysis published online in the table EMP07 Temporary Employees. Currently, this table is updated four times a year in February, May, August and November using the Quarterly Labour Force Survey (QLFS).

Learning outcomes:

  • To become more familiar with QLFS datasets.
  • To become more familiar with the weighting variable.

Data

The data used relates to an estimate for July-September 2024.

To follow the exercise, you need to access the relevant dataset from the UK Data Service: Quarterly Labour Force Survey, July - September, 2024.

One you have downloaded the data, save it somewhere accessible, for example in a folder named LFS_exercises.

Weighted and unweighted frequencies

In order to provide reliable estimates of population values, survey data needs to be weighted when analysed. Weights are variables whose values increase or decrease the relative importance of observations, depending on how likely respondents were to take part to the survey. Some weights are only designed to correct the relative importance of observations, whereas others in addition also enable calculating population totals - the latter are called grossing weights.

Below, we compare weighted and unweighted frequencies and percentages again.

We will be using as_survey_design(), a R function from the survey and srvyr packages that in effect creates a weighted version of our data.

Let us first examine the variable measuring - JOBTYP - whether respondents work in a temporary job or not:

table(mydata$JOBTYP)

          [-9] Does not apply                [-8] No answer 
                        34496                            17 
                [1] Permanent [2] Not permanent in some way 
                        23427                          1199 
round(100*prop.table(table(mydata$JOBTYP)),1)

          [-9] Does not apply                [-8] No answer 
                         58.3                           0.0 
                [1] Permanent [2] Not permanent in some way 
                         39.6                           2.0

… and create a version without missing values.

mydata <- mydata |> 
                  mutate (
                     JobTmp = ifelse(JOBTYP == "[2] Not permanent in some way",
                                      "Temporary",
                                      "Not temporary"),
                     JobTmp = ifelse(JOBTYP == "[-9] Does not apply" | JOBTYP == "[-8] No answer",
                                      NA,
                                      JobTmp),
                    JobTmp = as.factor(JobTmp)
                  )

table(mydata$JobTmp)

Not temporary     Temporary 
        23427          1199

We then load the required packages and create a weights-informed version of the data:

library(survey)
library(srvyr)
mydata.s<-mydata|> 
         filter(!is.na(PWT24) ) |> 
         as_survey_design(weights=PWT24)

Please note that we needed to remove observations with missing weights values, in effect observations that should not be taken into account to calculate population values. If we don’t we will get an error message.

We can now compute weighted frequencies and percentages using a survey specific command: svytable():

svytable(~JobTmp, mydata.s)
JobTmp
Not temporary     Temporary 
     27710056       1563699 
round(100*
       prop.table(
         svytable(~JobTmp, mydata.s)
         ),1
      )
JobTmp
Not temporary     Temporary 
         94.7           5.3
