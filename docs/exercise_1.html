Estimates of temporary employment

In this exercise, we will recreate an ONS labour market estimate published online in the table EMP07 Temporary Employees. Currently, this table is updated four times a year in February, May, August and November using the Quarterly Labour Force Survey (QLFS).

Learning outcomes:

  • To become more familiar with quarterly LFS datasets.
  • To become familiar with weighted population counts and their confidence interval
  • To understand how some ONS estimates are produced

Data

The data used in this exercise relates to an estimate published by the ONS for October-December 2024.

To follow the exercise, you need to access the relevant dataset from the UK Data Service: SN 9349: Quarterly Labour Force Survey, October - December, 2024.

We suggest that you create a folder named LFS_exercises as the working directory for this exercise – where syntax files and other materials will be stored. After downloading the data, save it in an easily accessible location within LFS_exercises, such as a subfolder named Data.

  2. Why are there many missing cases on the variables: JBTP101, FTPT and JOBTYP?

  1. INECAC05 records Basic economic activity (ILO definition) (reported)

  2. Most of the missing cases are due to the variables not being applicable to all respondents. For example, the variable FTPT applies only to individuals aged 16 and over who are in employment. Similarly, JBPT01only applies to respondents who indicated that their job was not permanent in some way (i.e. where JOBTYP = 2).

Getting weighted frequencies

To get correct estimates of population values, we need to use the weighting variable - PWT24.

We will use as_survey_design(), an R function from the survey and srvyr packages, to create a weighted version of our data.

Let’s first examine the variable JOBTYP, which indicates whether respondents work in a temporary job or not.

t<-table(
  Freq=as_factor(
    dataex1$JOBTYP
    )
  )

t
Freq
           Does not apply                 No answer                 Permanent 
                    36698                        15                     25104 
Not permanent in some way 
                     1252

Since we have missing values (e.g. ‘Does not apply’), we can mark them as system missing (NA in R) in order to get neater tables.

dataex1 <- dataex1 |> 
          mutate (JobTmp =case_when(
                  JOBTYP== 1 ~ "Not temporary",
                  JOBTYP == 2 ~ "Temporary",
                  JOBTYP == -9  | JOBTYP == -8 ~ NA),
                  JobTmp = as.factor(JobTmp)
          )


tm<-table(Freq=dataex1$JobTmp)
tm
Freq
Not temporary     Temporary 
        25104          1252

Let’s create a version of the data with the weights applied, which we will use in the rest of the analysis.

dataex1.s<-dataex1|> 
         as_survey_design(weights=PWT24)

… And compute the weighted frequencies of JobTmp.

We will look at the population counts first:

### Simple point estimates

Questions

  • Questions
  • Answers

  1. Do the frequencies change noticeably when the weight is applied?

  2. Using the code we used to create JobTmp above as guide, create a variable to indicate those working part time and examine their weighted and unweighted frequencies. You are going to need this variable later.

  1. Yes, the frequencies change quite a lot once we apply the weights — they become much higher. This is because the weights in the Labour Force Survey (LFS) are designed to sum to known UK population totals. That makes it easier to estimate overall population numbers.

    The LFS weights also account for the survey’s sample design: individuals who had a lower chance of being selected are given higher weights to correct for that. They also help adjust for different levels of non-response across subgroups in the population, which means the results are more likely to reflect the population accurately.

  2. The syntax below computes a variable recording whether respondents work part-time or not and produce weighted frequency tables.

 dataex1 <- dataex1 |> 
             mutate (
               PartTime = case_when(
                  FTPT == 3 | FTPT== 1 ~ "Not part-time",
                  FTPT == 4 | FTPT  == 2 ~ "Part-time",
                  FTPT == -9 | FTPT == -8 ~ NA),
               PartTime = as.factor(PartTime)
                  )


dataex1.s<-dataex1|> 
         as_survey_design(weights=PWT24)
