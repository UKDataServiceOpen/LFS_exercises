Exercise 1: Weighted vs. Unweighted Estimates of Mean Gross Weekly Earnings

Introduction

We compare the mean gross weekly earnings (GRSSWK) using weighted and unweighted estimates and examine their confidence intervals. The weighting variable used is PIWT24.

R Code

library(survey)
library(dplyr)
library(haven)

od24 <- read_dta(
        "~/Data/lfs/UKDA-9349-stata/stata/stata13/lfsp_od24_eul_pwt24.dta"
                    )



# Define survey design
od24.s <- svydesign(ids = ~1, weights = ~PIWT24, data = od24)

# Unweighted mean and CI
unweighted_mean <- mean(od24$GRSSWK[od24$GRSSWK>=0 & od24$AGE>=16], na.rm = TRUE)
unweighted_ci <- t.test(od24$GRSSWK[od24$GRSSWK>=0 & od24$AGE>=16 ])$conf.int

# Weighted mean and CI
svyby(~GRSSWK, ~ GRSSWK>=0, od24.s,svymean,vartype = "ci" )
     GRSSWK >= 0   GRSSWK     ci_l     ci_u

weighted_mean <- svymean(~GRSSWK, od24.s)

Interpretation

Weighted estimates account for survey design and better represent the population.

Questions

  1. Why is the weighted mean different from the unweighted mean?
  2. How does weighting affect the confidence interval width?
  3. Why do we use PIWT24 as the weighting variable?

### Answers 1. Weighting adjusts for sample design and differential response rates. 2. Weighted confidence intervals are usually wider due to increased variance. 3. PIWT24 ensures the estimates represent the UK population.

## Exercise 2: Comparing Confidence Intervals for Female Part-Time Employment

### Introduction We compute weighted confidence intervals for the proportion of female employees working part-time (FTPT == 2) in London (GOR9 == 7) and the North West (GOR9 == 2).

R Code

# Subset data by region and gender
london_females <- subset(od24, GOR9 == 7 & FTPT == 2)
nw_females <- subset(od24, GOR9 == 2 & FTPT == 2)

# Compute weighted proportions
prop_london <- svymean(~FTPT, subset(od24.s, GOR9 == 7 & FTPT == 2))
prop_nw <- svymean(~FTPT, subset(od24.s, GOR9 == 2 & FTPT == 2))

Interpretation

Regional variations exist in part-time employment among female employees.

Questions

  1. Why might the proportions differ between regions?
  2. What factors could influence confidence interval widths?
  3. Why do we use svymean() for proportions?

### Answers 1. Regional economic conditions and industry composition. 2. Sample size and variance in employment patterns. 3. It accounts for survey design and weighting.

## Exercise 3: Adjusting CI for Employment by Age Using Design Effects

### Introduction We adjust confidence intervals for the proportion of people in employment (ILODEFR == 1) across age bands (AGE) using published design effects.

R Code

# Compute weighted employment proportions by age
employment_by_age <- svyby(~ILODEFR, ~AGE, od24.s, svymean)

# Apply design effects (assuming we have a vector of effects)
design_effects <- c(...) # Values from LFS documentation
adjusted_se <- sqrt(coef(employment_by_age) * design_effects)

# Compute adjusted confidence intervals
adjusted_ci_lower <- coef(employment_by_age) - 1.96 * adjusted_se

Questions
